## 📌 Sobre este repositório

Este repositório funciona como a **central organizacional do projeto Carcará**, reunindo links, documentações, arquitetura geral e acesso a todos os subprojetos do ecossistema.

O Carcará é uma **arquitetura distribuída** composta por:

- 📱 Aplicativo mobile de coleta de dados em campo  
- 🧠 API inteligente de processamento geoespacial  
- 📊 Dashboard operacional em tempo real 

---

## 🧠 O que é o Carcará?

O **Carcará** é um sistema de inteligência geoespacial voltado ao **combate a incêndios florestais**, que transforma observações brutas de campo em **informações georreferenciadas de precisão**.

Ele coleta dados como:
- 📍 posição GPS do observador  
- 🧭 azimute (direção da visada)  
- 📐 pitch (ângulo de elevação)  

Esses dados são processados para estimar, via triangulação, a localização provável de focos de incêndio.

---

## 🎯 Objetivo do Projeto

O Carcará tem como missão principal:

> Transformar dados brutos de campo em inteligência geoespacial confiável para resposta rápida a incêndios florestais.
